# Reference artwork

These assets were extracted from the owner-provided mockups in `design/`. The original files are unchanged.

- `shop-1.png` through `shop-6.png`: storefront thumbnails from `shops-screen.png`.
- `shops-illustration.png`: illustration from `get-started-screen.png`.
- `shop-illustration.png`: illustration from `splash-screen.png`.
- `property-illustration.png`: illustration from `setup-property-screen.png`.

Only artwork and thumbnails are image assets. Layouts, cards, typography, charts, fields, icons, navigation, and controls are implemented as React Native components; full screen screenshots are not used as UI backgrounds.
